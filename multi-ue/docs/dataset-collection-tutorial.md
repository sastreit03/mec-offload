# Data set Collection Tutorial

Thus tutorial walks through how to make a campaign to generate data using the MEC server in the `multi-ue` directory.

## Set up Campaign yaml
First, generate the campaign yaml. The campaign yamls are located in `multi-ue/config/compaigns`. The latest schema used is schema_version = 2 in file `mec-review-pixel1-validation-v1.yaml`.
